# UbbExtract
Frames extractor tool for the tracks of Cryo's 1996 MegaRace 2.



## How to use
You will need your own MegaRace 2 files!
Open CMD and use this command:

```UbbExtract.exe <input.ubb> [outputFolder] [frameCount | all]```
